# README screenshot checklist

Add **real screenshots from your current build** here.

Recommended names:

- `core-mode.png`
- `command-center.png`
- `tool-in-action.png`

Before taking screenshots:

1. Hide or blur API keys, email addresses, tokens, local file paths, phone numbers, and other private information.
2. Use the current `jarvis-advanced` build.
3. Prefer a clean 16:9 or wide desktop capture.
4. Keep the app itself as the focus.
5. Do not use generated mockups in place of real product screenshots for the repository README.

After adding the images, uncomment the screenshot section in the root `README.md`.
